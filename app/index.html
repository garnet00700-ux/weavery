연결 코드로 연결

서버가 아직 없나요? (처음 설치)

  1. 안내받은 서버 시트 사본 만들기 링크를 열고 [사본 만들기]를 누릅니다. (내 구글 계정 · 내 드라이브에 만들어집니다)
  2. 복사된 시트 위쪽 메뉴 [전자계약 → ① 처음 설정] → 권한 허용
  3. [확장 프로그램 → Apps Script] → 오른쪽 위 [배포 → 새 배포] → 유형 웹 앱 · 실행 나 · 액세스 모든 사용자 → 배포 → 완료 화면의 웹 앱 URL 복사
  4. 시트로 돌아와 [전자계약 → ② 연결 코드 보기] → 웹 앱 URL 붙여넣고 저장 → 나온 코드를 복사해서 위 칸에 붙여넣기
고급: 주소 · 키 직접 입력
