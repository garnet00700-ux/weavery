계약·서류 작성기

처음 오셨나요? [회사 설정]에서 회사 정보와 구글 시트(서버) 연결을 먼저 해 주세요 — 연결 전에는 이 브라우저에만 저장돼 쿠키를 지우면 문서가 사라집니다.
연결 코드가 있으면 바로 붙여넣으면 됩니다.
서버 업데이트가 있어요 연결된 서버(구글 시트 안의 프로그램)가 예전 버전입니다.
서버를 만든 분(대표 계정)이 한 번만 바꿔 주면 팀 전체에 적용됩니다. (약 5분)
팀원은 할 일이 없습니다.
  1. 를 누릅니다.
  2. 크롬에서 서버 시트(구글 시트)를 엽니다.
    위쪽 메뉴 [확장 프로그램 → Apps Script]를 누릅니다.
  3. 새 창 왼쪽의 Code.gs를 누릅니다.
    코드 아무 곳이나 한 번 클릭하고 Ctrl+A (전부 선택) → Ctrl+V (붙여넣기) → Ctrl+S (저장)
  4. 오른쪽 위 파란 [배포] → [배포 관리] → 오른쪽 위 연필 모양을 누릅니다.
    버전 칸을 눌러 '새 버전'을 고르고 → 아래 [배포] → [완료].
    ⚠ '새 배포'를 누르면 안 됩니다. 주소가 바뀌어 연결이 끊깁니다.
  5. 작성기를 새로고침(F5)하면 이 알림이 사라집니다.
    자세한 그림 안내: 설치 안내 → 서버 업데이트

기존 견적서 불러오기

예전에 쓰던 견적서 파일을 올리면 품목 · 수량 · 금액과 의뢰자 정보를 찾아 옵니다.
엑셀(.xlsx · .csv)이 가장 정확하고,
한글(.hwp · .hwpx) · PDF · 워드(.docx)도 됩니다.
스캔한 사진 PDF는 읽을 수 없습니다.
PDF로 올리면 로고 · 도장 · 대표 색 · 표 머리 색도 찾아서 우리 견적서 디자인에 넣을 수 있습니다.
넣기 전에 아래 표에서 확인하고 고칠 수 있습니다.
체크를 끄면 그 줄은 빠집니다.

읽은 글자 보기 · 직접 붙여넣기
쓰던 양식 불러오기

쓰던 계약서 · 견적서 파일을 올리면 원본 디자인은 그대로 두고,
글자 · 품목 · 금액 · 조항을 모두 읽어 기본 양식처럼 고칠 수 있게 만듭니다.
PDF로 올리면 가장 정확합니다.

불러올 모습

이 파일은 원본 모양을 그대로 쓸 수 없어(한글 · 워드 · 엑셀),
읽은 내용을 작성기 기본 양식으로 옮깁니다.
원본 모양 그대로 쓰려면 [PDF로 저장]한 뒤 다시 올려 주세요.

불러올 모습

원본 디자인 그대로 불러옵니다.
품목 · 금액 · 조항 · 회사 정보는 왼쪽에서 기본 양식처럼 고칠 수 있습니다.

저장소를 내가 직접 만들었다면

  1. 구글 드라이브에서 '전자계약 서버' 구글 시트를 엽니다.
  2. 시트 위쪽 메뉴 [전자계약] → [② 연결 코드 보기]를 누릅니다.
  3. 창에 나온 WQ1. 로 시작하는 코드를 [복사]합니다.
  4. 이 창의 [저장소 연결하기 →]를 눌러 붙여넣습니다.

회사의 다른 사람이 만들었다면

  1. 저장소를 만든 사람에게 연결 코드나 팀원 초대 링크를 달라고 하세요.
  2. 초대 링크를 받았다면 주소창에 붙여넣어 여세요.
    저장소가 자동으로 연결됩니다.
